# Password Strength Analyzer 

A lightweight, responsive web application built with **HTML5**, **CSS3**, and **JavaScript** that evaluates password strength in real time and provides actionable security suggestions.

---

##  Features

- **Real-Time Evaluation:** Analyzes passwords instantly as you type.
- **Visual Strength Indicator:** Dynamic progress bar reflecting strength levels (e.g., Weak, Medium, Strong).
- **Security Criteria Checklist:**
  - Minimum length (e.g., 8+ characters)
  - Uppercase and lowercase letters
  - Numeric digits (0–9)
  - Special characters (`!@#$%^&*`, etc.)
- **Actionable Feedback:** Displays helpful hints to guide users toward creating stronger credentials.
- **Clean UI:** Simple, intuitive, and mobile-friendly design.

---

## Built With

- **HTML5:** Page structure and semantic layout
- **CSS3:** Custom styles, animations, and responsive design
- **JavaScript (Vanilla):** Password evaluation logic, regex validation, and DOM manipulation
